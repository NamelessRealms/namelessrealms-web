### ⚠️ 建議（不阻斷）

  的差分佐證處寫明「此步隱含假設 session 存續，依據為時間鄰近＋未登出確認」。

  建議入報告的截圖以 probe 頁為主；若必須附含帳號資訊的畫面，遮蔽後再入。
- **備份檔放 scratchpad 的耐久性**：scratchpad 是 session 專屬，實作側若中途卡死
  （F4 發生過），備份可能隨之消失。可接受——五個值 Yu 手上都有、最壞重填；
  建議 verification 據實記一句這個取捨，⛔ 不因此把備份改放 repo 工作樹。

  repo 工作樹」擦邊。實質可接受：1乙 管的是**骨架交付物**，A3 是任務包明文委派的
