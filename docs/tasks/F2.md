## 目標

白話：這個 repo 有兩筆小型技術債——
一、`yarn dev` 的終端輸出檔 `web.log` 被 commit 進了版控（它是本機產物，不該進 repo）；
二、`.gitignore` 檔尾被重複貼了一段樣板，其中混著兩條**不重複、不能弄丟**的規則。
本任務把 `web.log` 移出版控（檔案本身留在硬碟上）、補上忽略規則，
並把 `.gitignore` 整理成單一乾淨版本，**且忽略保護零退步**。

做完的樣子：`git ls-files` 查不到 `web.log`、工作目錄仍有它、`.gitignore` 無重複條目、
`.env` / `.vscode` / `web.log` 三者都被 `git check-ignore` 命中。

## 驗收步驟（正向 + 負向都要）

> 每條附**實際指令輸出**進 `F2-verification.md`，⛔ 不得用預期值冒充。

**正向：**
1. `git ls-files web.log` → **無輸出**（已移出版控）。
2. `ls -l web.log` → 檔案**仍在工作目錄**（未被誤刪；大小應仍為 1242 bytes）。
3. `git check-ignore -v web.log` → 命中 `.gitignore` 的 `web.log` 規則。

6. `grep -c '^/node_modules$' .gitignore`、`grep -c '^/build$' .gitignore`、
   `grep -c '^\.DS_Store$' .gitignore` → 各為 **1**（去重完成）。
7. `yarn build` → 成功，輸出貼報告（回歸基線，見上方裁示）。

**負向 / 守界：**
8. `git status --porcelain` → `app/layout.tsx`、`app/staff/page.tsx`、
